

# 🚀 Anirudh Sharma — 3D Data & AI Portfolio Website

## Overview
A stunning, dark-themed single-page portfolio for a **Data Specialist & AI Enthusiast**, featuring immersive animations, glassmorphism cards, animated counters, and data-visualization motifs — now with prominent AI/ML branding throughout.

## 🎨 Design Foundation
- **Dark navy background** (#0a0e27) with blue/purple/cyan accent palette
- **Glassmorphism** cards with backdrop blur
- **Google Fonts**: Space Grotesk (headings), Inter (body), JetBrains Mono (stats/code)
- **Gradient accents**: #667eea → #764ba2 → #f093fb
- Fully responsive, mobile-first layout

- Animated counters on scroll reveal

---

## 📱 Responsiveness
- Desktop: multi-column grids, full animations
- Tablet: adjusted columns, maintained effects
- Mobile: single-column, simplified animations, hamburger nav

---

## ⚡ Technical Approach
- **No backend needed** — fully static frontend
- Framer Motion for animations
- Recharts for data visualizations
- React Hook Form + Zod for contact form (mailto or toast confirmation)
- Component-based architecture with reusable animated cards
